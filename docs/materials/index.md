# 材料准备

## 套磁导师需要准备的材料

- **[套磁邮件模板](./email-template)**：准备一个通用模板，不同老师根据情况进行微调即可。
- **[个人简历](./resume)**：个人基本情况描述。
- **[个人陈述](./personal-statement)**：邮件正文部分，后续夏令营报名可以复用。
- **成绩单与排名证明**：需要有学校盖章的文件，上科大学生可以直接从"egate->教务系统->学习管理"中找到"电子成绩单获取"和"成绩排名获取"中下载电子版pdf。


## 报名夏令营需要准备的材料


- **证件**：
    - **证件照**：需要符合要求的电子版，通常要求白底，但建议准备红蓝白三版，可以使用支付宝小程序或者免费网站换底。
    - **身份证**：正反面，需要扫描件或照片，确保清晰可见。
    - **学生证**：需要扫描件或照片，确保清晰可见。
    - **学生卡**：需要扫描件或照片，确保清晰可见。
- **[个人简历](./resume)**：个人基本情况描述，建议准备中英文两版。
- **[个人陈述](./personal-statement)**：准备不同字数的版本，不同学校夏令营/预推免报名时要求的字数不同，线下参营时要求也不同。
- **成绩单与排名证明**：需要有学校盖章的文件，上科大学生可以直接从"egate->教务系统->学习管理"中找到"电子成绩单获取"和"成绩排名获取"中下载电子版pdf。
- **[推荐信](./recommendation-and-proof)**：提前沟通推荐老师，一般准备2封即可，有条件可以准备3封，有的学校不需要，有的只需要1封。
- **四六级成绩单**：从[官网](https://cjcx.neea.edu.cn/html1/folder/21045/4883-1.htm)查询后，下载pdf电子版成绩证明。
- **教育部学籍在线验证报告**：访问[学信网的学信档案网页](https://my.chsi.com.cn/archive/bab/index.action)，登录后，点击"教育部学籍在线验证报告"的查看即可下载pdf电子版验证报告（若过期，则需点击"延长有效期"）。
- **其他证明**：
    - **竞赛获奖证明**：如果有相关竞赛获奖经历，可以准备相关证明材料。
    - **发表论文**：如果有相关论文发表经历，可以准备相关证明材料。
    - **实习经历**：如果有相关实习经历，可以准备相关证明材料。



## 线下参营需要准备的材料

- **[面试PPT](./interview-ppt)**
- **身份证及其复印件**
- **学生证**
- **简历打印版**（多打几份，中英文版）
- **证明材料打印版**：根据各个学校不同要求，按需要打印即可
