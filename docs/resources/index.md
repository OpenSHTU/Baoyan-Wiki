# 推荐资源



## 资源分享类
[CSWIKI](https://csbaoyan.top/): 规模最大，最权威的保研资源库网站，包含了大量的保研经验、材料和信息，覆盖了全国各大高校和专业。虽然主要针对CS学生，但是对其他专业的学生也有很大参考价值和意义。

[强弱com](http://t.cn/A6EgfCAC): 各个学校各个学院的强弱com，但时间较早，有些信息可能过时。同时也可以在CSWIKI里找到一些[信息](https://csbaoyan.top/%E4%BF%9D%E7%A0%94%E6%8C%87%E5%8D%97/%E9%99%A2%E6%A0%A1%E8%A7%A3%E6%9E%90/)

## 夏令营信息获取类
[csbaoyan-ddl](https://ddl.csbaoyan.top/): 由CSWIKI维护的保研信息发布平台，提供了最新的各种夏令营预推免信息。一般每年的四月中旬到下旬开始维护，开始更新一些保研夏令营的信息。

[星刻保研网](https://xingkebaoyan.com/list.html)：由第三方辅导机构搭建的新型网站，在2026年开始建立并更新各种夏令营预推免信息，涵盖除了cs专业的各种夏令营预推免信息。但是毕竟是第三方机构建立的网站，含有部分付费保研宣传的广告，但是目前是一个较为绿色的，较为亲民的网站。功能相比csbaoyan-ddl更丰富。

**保研岛**：微信小程序，同样为各种夏令营预推免信息发布平台，但是也是第三方保研机构创建，具有较大盈利性质，保研辅导相关广告更多。


## 导师评价类

[导师评价网站汇总](https://zhuanlan.zhihu.com/p/514592085)：这是一篇知乎文章，里面汇总了现在还存在的导师评价网站，包括对它们的介绍，属于导航性质的文章。

[导师评价网](https://daoshipingjia.net/)：这是一个收费性质的网站，但是提供了大量的导师评价信息，覆盖了全国各大高校和专业。

[研控](https://www.yankong.org/review): 这是免费的导师评价网站，需要翻墙访问。
