# 保研基础

> 对保研不是特别了解的同学，建议先阅览这一章，有助于快速建立对保研的基本认识。

> [!note]
> 本章节内容由上海科技大学2021级学长整理

## 保研黑话大全

### 一、 保研基本概念

* **推免资格(保研资格)**：根据本科学学校的综合排名，由教育部决定是否提供给你免试攻读研究生的资格(不需要考研)，拥有保研资格后只要你想要去的学校给你发放offer，你就可以去那里读研了。具体的推免名单和排序方法是本校学院决定的。
* **入营**：获得参与目标院校的夏令营/预推免的资格
* **夏令营**：去报考的学校参加笔试、面试等考核，表现优异的同学会被发放优秀营员（优营）。
* **预推免**：其实就是第二次夏令营，但他开始的时间非常晚，通常是在9月中下旬了，此时距离系统开放往往只剩几天的时间了，比较考验心态。（一般入营bar会低，考试会难一些，导师权利会大一点）
* **优秀营员/优营/offer**：优秀营员，代表对方学校对你的认可和录取意向，优营效力视具体学校而定。有些优营=拟录取，直接 9.28 填系统即可，对方学校会马上在教育部系统里将你录取。有些优营仍然需要进入预推免，再次参加考核。具体参考学校政策/往年情况。也有一些其他的形式。
* **口头承诺/Oral Offer**：通常是导师个人的口头或邮件表达的录取暗示/邀约/承诺，但是这种 offer 的效力会受很多主客观因素影响，甚至可能是学生和导师之间的误会。教授有保护自己的技巧和回答方式。
* **保研成功** = 拿到保研资格 + 并被一所学校发 offer
* **系统/志愿系统/学信网/教育部系统**：教育部主管的管理学校和学生高校录取情况的网站，在这个系统中显示的录取关系通常认为有正式效力。

### 二、 保研前准备

#### 1. 选择学位
* **学硕**：3年，学士型研究生，偏向学术研究，可以直接读博/硕博连读。
* **专硕**：2-3年，专业型研究生，偏实际应用，学费普遍比学硕贵（有的不含宿舍），需实习。
* **直博 (Ph.D.)**：5/6 年毕业，直博不经过硕士阶段，毕业时只拿博士学位。如果放弃，一些项目可以选择转硕，然后以硕士毕业；一些项目则只能拿本科学位。
* **工程博士 (Eng.D)**：一种说法是与专硕的特点类似

#### 2. 选择学校
* 学校在保研时基本可以分成强 com 和弱 com。**com**: committee，强弱指其在接收学生中老师/学校的权力强弱
* **强 com**：招生办话语权大于导师，录取方式、名额增减等主要由招生办决定，而不是导师。招生办权力高，一般看硬性条件多：学校的 title，GPA，竞赛、（科研）。
* **弱 com**：导师话语权高，一般要套磁，老师要你就行。大多数学校是强弱结合：即委员会以较弱的条件筛一波，随后允许导师选择，导师也有强行抬人的权利，不过大多数时间按照综合排名。[强弱信息参考](http://t.cn/A6EgfCAC)
* **title**：通常指学校的层次，包括 985、211、双一流等，有时会作为入营录取的隐形门槛。
* **rank/rk**：专业排名。
* **bg**：background，指你的院校专业、专业排名、英语成绩和科研竞赛等综合背景。
* **bar**：即入营门槛，不同层次的院校 bar 有所不同，在本科学校，成绩排名，英语四六级成绩，竞赛，科研论文等方面都会有要求。
* **oq**：over qualified，学生报名比自己本科院校或能力水平低的院校，一般这样做是为了保底，但有时候也会因为 oq 而被院校主动放弃。

#### 3. 选择导师
* **套磁**：touch，提前和想跟的老师联系，介绍自身背景情况，表明读研意愿争取导师名额。
* **AP**：assistant professor，助理教授，也可以带研究生。一般新AP竞争压力较小，他们也愿意和学生沟通，并且大部分为了尽快晋升，一般对科研态度很积极，有时候是一个不错的选择。

### 三、 保研后期

* 在参加夏令营/预推免中拿到优秀营员后，根据不同的政策有放鸽子的情况发生：
* **学生放鸽子**：接受了多个学校的优秀营员，然后主动通知其中的某些学校不想去了。
* **学校放鸽子**：学校为了避免自己被过多学生放鸽子，有可能超发 offer (offer数量多于招生指标)，最终根据排名依次录取。
* **导师放鸽子**：导师做出明确的口头承诺后，由于各种主客观原因导致最终无法录取你(一般是学校原因)。注意，导师放鸽子不仅限于928确认去向之前，有的老师可能在已经录取你之后，由于各种不可抗因素，导致无法让你入学，这种情况也算是导师放鸽子，但是一般极少出现。
* **928**：关键的时间节点，在学信网填报志愿的时间。通常这天过后放鸽子被视作是不道德的。
* **九推十推**：学信网接受拟录取这一环节其实持续了 20 多天，这是因为其实大部分人在 929 就会接受拟录取了，同时有的海王学生会将自己一直没有放掉的 offer 释放，导致有些学校被鸽。这些被鸽的学校就会去紧急联系其他候补的学生。这一过程可能持续到九月底、十月，所以叫做九推、十推。如果夏令营和预推免都没有满意的 offer，那可以尝试九推、十推捡漏。
* **候补/wl/waiting list**：候补队列，许多学校防止优营鸽太狠，优营不去以后一般从 wl 开始往后顺延录取。(有的学校优营靠后也算 wl)
* **捡漏**：9.28 之后，有些院校开系统后招不够人进行补录，可能拿到高性价比的 offer，甚至被梦校捞起来。
